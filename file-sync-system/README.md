# Distributed File Synchronisation System

An advanced Python software engineering project demonstrating client-server architecture,
file I/O, sockets, and hashing for file synchronisation.

## Features
- Client-server communication using sockets
- File transfer and storage
- Modular project structure
- File hashing utilities

## How to Run
1. Run server/server.py
2. Run client/client.py
3. Files in client/sync_folder will be synced to server/storage
